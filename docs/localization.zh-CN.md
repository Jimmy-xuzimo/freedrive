# 网页端中文支持

网页端提供简体中文（`zh-CN`）与英文，覆盖登录、文件管理、分享、内置查看器和编辑器、安全中心，以及管理后台。桌面同步客户端和 Android 客户端不在本次适配范围内。

## 切换语言

- 默认使用英文，不读取浏览器语言或旧的个人语言偏好。登录页和账号菜单不提供语言选择器。
- 管理员在原有的“设置 → 常规 → 默认语言”中选择“简体中文”并保存，页面自动刷新，站点网页采用中文；选择 English 可切回英文。
- 下拉框仅保留 English、简体中文、AZ、TR、DE。原有 `az`、`tr`、`de` 设置值继续保留；这些值暂沿用英文界面，不代表已经实现相应翻译。

语言来源：管理员保存的站点默认语言，未配置时使用英文。

## 实现方式

- `cmd/freedrive/web/locales/zh-CN.js`：简体中文词条，以英文原文为键。
- `cmd/freedrive/web/js/i18n.js`：语言解析、词条查找、参数插值、日期与相对时间、错误消息与状态标签。
- `cmd/freedrive/web/js/bootstrap.js`：先确定语言，再加载界面脚本，避免初始状态和菜单标签混用两种语言。
- 静态 HTML 通过 `data-i18n` 及 `data-i18n-title`、`data-i18n-placeholder`、`data-i18n-aria-label` 标注；动态内容在生成处显式调用 `I18n.t()`。
- `GET /api/v1/public/config` 只返回站点语言，不公开其他管理设置。

示例：

```javascript
I18n.t('Share {0}', { 0: filename });
// 简体中文：分享 filename
```

文本翻译只发生在应用自己的显示位置，不使用全局 DOM 替换、浏览器翻译或 MutationObserver。文件名、用户输入、评论、文件内容、权限值、搜索参数、CSS 类名和图标名称保持原值。插入 HTML 时仍需保留原有的 `escapeHtml` 调用。服务端 API 错误标识保持英文，在网页显示边界翻译，避免影响客户端的错误判断。

日期和相对时间采用当前界面语言；中文字体添加 Windows、macOS 和 Linux 常见 CJK 字体回退。

## 验证

在仓库根目录执行：

```shell
node --test scripts/test-web-i18n.cjs
go test ./...
go build -o freedrive ./cmd/freedrive
```

Node 测试不需要安装前端依赖，验证默认英文、中文别名、词条覆盖、参数插值、用户内容保留、搜索参数和存储分类标识。Go 测试包含后台默认语言读取。

人工验收建议：切换中英文并刷新；上传、打开和编辑中文文件名的文件；新建文件夹；检查分享权限和搜索筛选；将文件移至回收站后恢复；浏览后台全部设置页；用窄屏检查登录界面。
